# Input WAV Files

Place the phonocardiogram (PCG) WAV recordings you want to process in this folder.

The audio files are excluded from Git to avoid uploading large datasets to the repository.

## Dataset

Example recordings can be obtained from the CirCor DigiScope Phonocardiogram Dataset on PhysioNet:

https://physionet.org/content/circor-heart-sound/1.0.3/

Once you have downloaded a recording, place its `.wav` file in this folder and run `pcg_filter.py`.
